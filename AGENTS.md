# Viewy development rules

- Read `docs/PRODUCT_SPEC.md` before implementing future tasks.
- Work on one development milestone at a time.
- Favor correctness, simplicity, and maintainability.
- Keep mathematical calculations separate from UI code.
- Use good Kotlin and Android development practices.
- Implement tests for important logic.
- Avoid unnecessary dependencies and overengineering.
- Maintain offline functionality.
- Do not introduce analytics or advertising.
- Run relevant tests after modifications.
- Never claim tests passed without executing them.
- Never make changes outside the current task scope.
- Use conventional Git commit messages.
- Do not push to GitHub without explicit permission.
